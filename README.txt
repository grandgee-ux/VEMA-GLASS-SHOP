GLASS MART - OPERATIONAL FRONT-END DEMO
=======================================

TECHNOLOGY
- HTML, CSS and JavaScript only
- No PHP and no database
- Browser localStorage is used to save demo business data on this device/browser.

HOW TO OPEN
1. Extract the ZIP file.
2. Open the Glass_Mart_Login_Role_Gate folder.
3. Double-click index.html.
4. Sign in with one of the demo accounts.
5. You are sent directly to that user's dashboard.

DEMO ACCOUNTS
Admin:    username admin      password admin123
Staff:    username staff      password staff123
Customer: username customer   password customer123

WHAT WORKS IN THIS DEMO
ADMIN
- Add products with category, price and opening stock.
- View the product catalogue and delete products.
- View recorded sales and order totals in reports.
- Save basic business profile settings.
- View the included demo staff accounts.

STAFF
- Record walk-in sales.
- Select a product, quantity and payment method.
- Complete remote customer orders.
- View recorded sales.
- Completing a sale reduces product stock.

CUSTOMER
- Browse the product catalogue.
- Add products to a cart.
- Change quantities and remove cart items.
- Submit an order with contact and payment preference.
- View order status in My Purchases.

DATA AND IMPORTANT LIMITATIONS
- Products, cart, orders, sales and settings are saved in this browser's localStorage.
- Data is shared between the three demo roles when they use the same browser on the same device.
- Data is not synchronised to another computer or browser and may be lost if browser site data is cleared.
- This is a demonstration, not a production system. Client-side login and role restrictions can be bypassed.
- No real M-Pesa, card or bank payment is processed.
- Staff account management is a display-only sample. Real account creation and secure authentication need a server.
- For a live multi-user business system, use a backend and database with server-side access controls.
